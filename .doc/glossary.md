# Glossary

- **RAG** — Retrieval-Augmented Generation.
- **RLS** — PostgreSQL Row Level Security.
- **MCP** — Model Context Protocol; tool interface between agents and external systems.
- **ADR** — Architecture Decision Record.
- **HLD** — High-Level Design.
- **LLD** — Low-Level Design.
- **Iteration** — GitHub Project two-week planning period.
- **Review Cycle** — one automated fix/re-review loop; not the same as Iteration.
- **Test** — non-production environment where agent write access may be permitted.
- **Production** — live environment; no autonomous direct database writes.
