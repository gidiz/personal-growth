## Product

**Personal Growth, Mental Health & Retrospective OS**

A private personal intelligence system that helps the user:

> Capture → Remember → Connect → Reflect → Learn → Act

It combines daily execution, baseline/mood tracking, knowledge capture, challenge/decision reflection, AI-assisted ingestion, trends, retrospectives, and semantic personal-memory search.

## Core Product Promise

> Spend very little effort capturing today and receive increasing value from your own history over time.

The system should feel like a personal memory/retrospective layer, not a spreadsheet that the user must constantly maintain.

## Core Loop

1. Choose up to three Anchor Goals.
2. Capture text/voice/image with low friction.
3. Complete a short Daily Pulse.
4. AI organizes when useful; user remains in control.
5. Historical data becomes searchable and analyzable.
6. Weekly/monthly retrospectives turn history into lessons.
7. Lessons can be reused in future situations.

## MVP Areas

- Authentication
- Daily Pulse
- Anchor Goals
- Insights
- Challenges
- Basic Decision Journal
- Voice/text capture
- Weekly Review
- Basic Trends
- Semantic Brain Search

## Product Principles

- Daily Pulse should typically take under 30 seconds.
- AI organizes; the user owns and can correct.
- Correlation is not causation.
- Privacy is a product requirement.
- User input must survive AI/network failure.
- Prefer simplicity over speculative complexity.
