# Naming Rules

- canonical product terms live in `.doc/glossary.md`; do not invent synonyms for core domain entities without updating the glossary/PRD.
- React components: PascalCase.
- hooks: `useX`.
- database: snake_case.
- environment variables: SCREAMING_SNAKE_CASE.
- branch names: `feature/`, `task/`, `bugfix/`, `security/`.
- preserve canonical agent casing such as `QA` and `DevOps`.
