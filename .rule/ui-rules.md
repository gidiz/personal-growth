# UI Rules

- NativeWind is the primary styling layer.
- primitives live under `components/ui/`.
- loading, empty, error, and offline states must be considered.
- Hebrew RTL and English LTR are first-class.
- Web interactive controls must be keyboard accessible.
- interactive controls require accessible names/labels and appropriate semantic roles.
- visible focus behavior must not be removed without an accessible replacement.
- do not encode meaning using color alone.
- touch targets must be appropriate for mobile interaction.
